打包（Windows，在项目根目录用 PowerShell 执行）

装依赖:
    py -3 -m venv .venv
    .venv\Scripts\python -m pip install -r requirements.txt pyinstaller

出包：

    .venv\Scripts\python -m PyInstaller --noconfirm --clean --onefile --windowed --name "Ultra AC" --icon "$PWD\assets\icon.ico" --add-data "$PWD\assets;assets" --paths src --distpath "$env:USERPROFILE\Desktop" --workpath "$env:TEMP\ultra_ac-build" --specpath "$env:TEMP\ultra_ac-build" main.py
