\# Ultra AC



一款好用轻巧且高颜值的单文件连点器。使用 PySide6 绘制的 Material Design 3 Expressive 界面。使用 Python3.14.8开发。





\## 功能



| 功能 | 说明 |

| --- | --- |

| 点击速度 | 1–10000 CPS。滑杆可调节 1–1000 CPS，更高的CPS预设值可以在上方输入框输入 |

| 切换 / 按住（推荐） | 可以通过快捷键开始/停止连点，也可以长按鼠标对应键连点 |

| 鼠标按键 | 左键 / 中键 / 右键 |

| 拟人化间隔 | 在设定速度上叠加随机间隔 |

| 随机坐标内抖动 | 每次点击在 ±N px 内随机偏移 |

| 鼠标晃动急停 | 点击过程中快速剧烈摇晃鼠标停止 |

| 悬浮窗 | 置顶胶囊可实时显示当前 CPS |



\---



\## 配置文件



路径：`%APPDATA%\\Ultra AC\\settings.json`



| 键 | 含义 |

| --- | --- |

| `hotkey` | 当前热键 |

| `mode` | `hold` / `toggle` |

| `button` | 鼠标按键 |

| `cps` | 点击速度 |

| `human` | 拟人化间隔 |

| `jitter\_on` / `jitter` | 随机抖动设定 |

| `shake` | 鼠标晃动急停 |

| `hud` | 悬浮窗显示 |

| `close` | 关闭窗口行为：0 最小化，1 退出 |

| `on\_top` | 窗口置顶 |

| `theme` | `dark` / `light` |

| `tray\_tip` | 首次最小化到托盘是否已提示 |

\## 已知问题



\*\*高CPS造成的偏差和卡顿\*\*：CPS高于1000时，预期与实际CPS可能偏差较大，并且造成严重性能问题。
